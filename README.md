| 软件 | 版本 | 检测方式 |

| MySQL | 8.0+ | 自动启动，首次自动建库 |
| Node.js | 16+ | 自动检测 PATH |

### 启动方式

```
双击项目根目录的 start.bat
```

弹出三个窗口：主控窗口（显示进度）→ 后端窗口(8090) → 前端窗口(3000)。

等后端窗口出现 `Started ChemicalMeasurementApplication` 后，浏览器访问 `http://localhost:3000`。
